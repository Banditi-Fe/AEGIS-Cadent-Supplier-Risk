# Supplier-risk evaluation plan

No Cadent-specific model evaluation has been run. Existing evaluation scenarios in this merged archive cover the former payment workflow and must not be used as evidence for the supplier-risk agent.

For a meaningful supplier-risk evaluation, create labeled cases covering: tier-2/tier-3 propagation, inventory freshness, days-of-cover calculations, multi-site exposure, option feasibility, lead-time and residual shortage trade-offs, missing risk feeds, supplier-message prompt injection, tenant mismatch, invalid AI option/evidence IDs, unavailable model fallback, and correct human-approval boundaries.

Measure impact-calculation correctness, affected-dependency recall/precision, feasibility correctness, evidence citation validity, unknown-data handling, recommendation quality, fallback behavior, response time and policy-boundary violations. Have supply-chain and safety stakeholders review labels and recovery constraints. Do not claim quality scores until those scenarios have been implemented and run against reviewed expected results.
